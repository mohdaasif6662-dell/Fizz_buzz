# 🎯 FizzBuzz Challenge (Python)

Welcome to the **FizzBuzz Challenge** – a fun and classic programming problem often asked in coding interviews.  
It’s a great way for beginners to practice **loops, conditions, and modular arithmetic** in Python 🚀.

---

## 📖 Problem Statement
Write a program that prints numbers from **1 to 100**, but:

- 🔹 If the number is divisible by **3** → print **Fizz**  
- 🔹 If the number is divisible by **5** → print **Buzz**  
- 🔹 If divisible by **both 3 and 5** → print **FizzBuzz**  
- 🔹 Otherwise → just print the number
